# Contributing to google-news-url-decoder

Thank you for your interest in contributing to `google-news-url-decoder`! We welcome all contributions, including bug fixes, feature requests, and documentation improvements.

## Setup Instructions

To get started with local development:

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/your-username/google-news-url-decoder.git
   cd google-news-url-decoder
   ```
3. **Install dependencies**:
   ```bash
   npm install
   ```

## Running Tests

Before submitting a Pull Request, please ensure all tests pass:

```bash
npm run test
```

If you are testing live URL decoding, you can run:

```bash
npm run test:live
```

## Pull Request Guidelines

1. Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Write clean code and adhere to the project's existing code style.
3. Make sure to add tests for any new functionality or bug fixes.
4. Commit your changes with descriptive commit messages.
5. Push to your branch and open a Pull Request (PR) against the `main` branch of the original repository.
